# Radar de tecnologías emergentes · AECODE

Panel educativo con 12 tarjetas, cuatro familias, búsqueda, filtros, fuentes y selección personal en el navegador. Incluye ejemplos y pilotos propuestos para arquitectura, ingeniería y construcción.

## Ver el panel

https://apalpan.github.io/aecode-radar-tecnologias/

## Uso local

Descarga `index.html` y ábrelo con un navegador moderno. Logo, fuente, estilos y datos están incrustados. No requiere instalar dependencias ni configurar claves. Las fuentes externas necesitan internet.

La selección se conserva en localStorage cuando el navegador lo permite; no se sincroniza entre dispositivos. El sitio web necesita conexión para cargar. El HTML descargado funciona sin conexión.

## Publicación

GitHub Pages: rama `main`, carpeta raíz. `.nojekyll` sirve el HTML estático. Para actualizar, modifica `index.html` y publica un commit en `main`.

## Fuentes y alcance

Definiciones con referencias de IBM, NIST, Microsoft Learn y DOE consultadas el 17/10/2026. Las fichas distinguen definiciones de ejemplos y pilotos didácticos. Es una selección editorial que incluye tecnologías emergentes y habilitadoras; no es un ranking de adopción ni una promesa de retorno.
